Beállítások

Indítás a Windows-zal
Bejelentkezéskor magától elindul a tálcára (a régi program automatikus indítását lecseréli).
Bezárás
Az ablak bezárásakor a program a tálcán fut tovább. Kilépni a tálca ikon jobb gombos menüjében lehet.
Alvás megakadályozása
Amíg a program fut, a gép nem megy alvó módba (a kijelző kikapcsolhat), különben nem szólna a csengő.
Bekapcsolva
Adatok mappája
Itt vannak a beállítások (beallitasok.json), a hangok és a napló. Biztonsági mentéshez elég ezt a mappát lemásolni.
Napló
Minden csengetés ide kerül, így utólag is ellenőrizhető, mikor szólt.
